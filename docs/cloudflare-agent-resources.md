# Cloudflare Agent Resources

Cloudflare publishes agent-friendly documentation and MCP servers for coding agents that work on Cloudflare projects.

## Documentation

- Docs for agents: `https://developers.cloudflare.com/docs-for-agents/`
- Agent setup prompt: `https://developers.cloudflare.com/agent-setup/prompt.md`
- Pages docs: `https://developers.cloudflare.com/pages/`
- Wrangler docs: `https://developers.cloudflare.com/workers/wrangler/`

## MCP Servers

- Cloudflare API MCP: `https://mcp.cloudflare.com/mcp`
- Cloudflare Docs MCP: `https://docs.mcp.cloudflare.com/mcp`
- Cloudflare Bindings MCP: `https://bindings.mcp.cloudflare.com/mcp`
- Cloudflare Builds MCP: `https://builds.mcp.cloudflare.com/mcp`
- Cloudflare Observability MCP: `https://observability.mcp.cloudflare.com/mcp`

The current Codex environment has the Cloudflare API MCP and Cloudflare Docs MCP configured. Restart or reload the agent if a newly added MCP server is not visible in the tool list.
